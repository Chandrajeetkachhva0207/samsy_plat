# मा नर्मदा वेबसाइट — तुझा (frontend) वाटा

## टीम वाटप
- मित्राने केले: मेनू, फूटर, मुख्यपृष्ठ, आमच्याविषयी, संस्थापक अध्यक्ष, गुरुकुल, उपक्रम, विद्यार्थी व सुविधा
- तू (मी तुझ्यासोबत): बाकीची ७ पाने — खाली यादी
- तिसरा developer: backend + admin panel (अजून सुरू नाही)

**तुझ्या प्रश्नाचे उत्तर:** हो — गॅलरी फोटो, व्हिडिओ YouTube लिंक, अहवाल PDF, कार्यक्रम — हे सगळे पुढे admin मधून भरले की website वर दिसतील. पण तेवढ्यासाठी थांबायची गरज नाही. मी पाने अशी बनवतो की सगळा मजकूर आणि फोटोंची यादी एकाच फाईलमध्ये (`src/content/`) राहील. Backend तयार झाल्यावर त्या एका जागी data जोडला की सर्व पाने आपोआप admin चा डेटा दाखवतील — पानांचे डिझाइन पुन्हा करावे लागणार नाही. म्हणजे तुझे frontend काम backend आधी पूर्ण होऊ शकते.

## पहिली पायरी
मित्राची सगळी फाईल जशी आहे तशी या प्रोजेक्टमध्ये घेतली जाईल — डिझाइन बदलणार नाही.

## जी पाने मी बनवणार
1. **कार्यक्रम (/events)** — यादी (नाव, तारीख, वार, वेळ, ठिकाण, प्रमुख व्यक्ती, माहिती, फोटो) + प्रत्येक कार्यक्रमाचे स्वतंत्र पान. येणारे व झालेले कार्यक्रम वेगळे.
2. **फोटो गॅलरी (/gallery)** — विभाग: गुरुकुल, विद्यार्थी, वारकरी, बाल संस्कार शिबिर, धार्मिक, सांस्कृतिक, सामाजिक, विशेष. फोटोवर क्लिक करून मोठा दिसेल.
3. **व्हिडिओ (/videos)** — YouTube लिंकवरून व्हिडिओ कार्ड (शीर्षक, तारीख, माहिती), जागेवरच चालेल.
4. **कार्य अहवाल (/reports)** — वर्षानुसार अहवाल, "पाहा" व "डाउनलोड" बटण.
5. **भविष्यातील योजना (/future-plans)** — स्वतःची जागा, निवास, भोजनगृह, वर्गखोल्या, अभ्यासिका, सभागृह, क्रीडांगण, ग्रंथालय इ. — स्पष्ट "प्रस्तावित" असे लिहून.
6. **सहकार्य करा (/support)** — संस्थेच्या अधिकृत बँक/UPI माहितीची जागा (client कडून आल्यावर भरायची). वैयक्तिक खाते नाही.
7. **संपर्क (/contact)** — पत्ता, फोन, ई-मेल, Google नकाशा, संपर्क फॉर्म (नाव, मोबाईल, ई-मेल, विषय, संदेश). फॉर्म दिसेल व तपासला जाईल; संदेश पाठवण्याची जोडणी backend आल्यावर.

## सगळीकडे लागू
- प्रत्येक पानाला स्वतःचे शीर्षक/वर्णन (SEO), sitemap, robots
- मोबाईल, टॅबलेट, लॅपटॉप — सर्वांवर व्यवस्थित; मराठी मजकूर वाचायला सोपा
- खरे आकडे/दावे मी तयार करणार नाही — नमुना मजकूर, client चा डेटा आल्यावर भरायचा
- विद्यार्थ्यांची खासगी माहिती (आधार, पत्ता, मोबाईल, जन्मतारीख) कुठेही नाही

## Backend developer साठी नोंद
पानांना लागणारा डेटा एकाच ठिकाणी आणि एकाच रचनेत ठेवतो, म्हणजे त्याला admin बनवताना काय-काय fields लागतील ते तयार मिळेल.
